# 🌍 Euro Bangla Global Ltd - Student Portal & CRM System

A comprehensive, lightweight Student Portal and CRM web application built for **Euro Bangla Global Ltd** to streamline study-abroad consultancy workflows, document tracking, and secure client interactions.

---

## 🚀 Key Features

*   **Secure Authentication (Login & Registration):** Students can easily register and log in using their phone numbers and secure passwords without complex database setups.
*   **Interactive Student Dashboard:** Post-login dashboard providing a centralized view of personal status, service categories, and document checklists.
*   **Direct Document Upload System:** Allows students to upload necessary documents (Passport, Transcripts, Certificates, etc.) directly, which automatically sync with backend storage.
*   **Google Drive & Sheets Integration:** Powered by Google Apps Script and Google Sheets/Drive as a cost-effective, scalable serverless backend.
*   **Admin Override Capabilities:** Administrative staff have full access to manually verify, update, or upload documents on behalf of students if required.
*   **Responsive UI/UX:** Clean, modern, and mobile-friendly design tailored for global education consultancy services.

---

## 🛠️ Technology Stack

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Backend & API:** Google Apps Script
*   **Database:** Google Sheets (`Users` & `Documents` tabs)
*   **File Storage:** Google Drive API (`Student_Uploads` directory)

## ⚙️ Setup & Installation Guide

To run or deploy this project locally or for production:

1. **Clone the Repository:**
bash
git clone [https://github.com/your-username/euro-bangla-global.git](https://github.com/your-username/euro-bangla-global.git)


2. **Google Sheet & Apps Script Setup:**
* Create a Google Sheet named `Euro Bangla Student Portal` with two tabs: `Users` and `Documents`.
* Open **Extensions > Apps Script** and paste the backend script.
* Deploy the script as a **Web app** (`Execute as: Me`, `Who has access: Anyone`).
* Copy the generated Web App URL.


3. **Configure Frontend:**
* Open `script.js` and paste your deployed Google Apps Script Web App URL into the respective endpoint variables.


4. **Run Locally:**
* Open `index.html` in any modern web browser or use a live server extension (e.g., in VS Code).
